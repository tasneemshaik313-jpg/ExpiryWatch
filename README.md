# ExpiryWatch

Smart product expiry tracking using Flask, OCR, OpenCV, SQLite and Tesseract.

Features include front/back product photos, OCR date detection, MFG + shelf-life expiry calculation, manual date fallback, confidence verification, smart expiry risk score, in-app alerts, search, history and product details.

Run locally with `python app.py`. Docker installs Tesseract and ZBar for production deployment.
